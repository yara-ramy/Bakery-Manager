# Bakery Manager
A custom Odoo 19 module developed to simplify bakery management by providing an integrated system for managing products, customer orders, and bakery information.

# Features:
- Manage bakery products
- Shopping cart functionality
- Create and manage customer orders
- Order lines with automatic calculations
- Bakery information management
- Customer profile page
- Checkout interface
- User groups and access permissions
- Cart wizard for streamlined operations

# Technologies used:
- Odoo 19
- Python
- XML
- PostgreSQL

# Installation:
- Clone this repository
- Copy the 'my_bakery' module into your custom addons directory
- Add the addons path to your odoo configuration
- Update the Apps list
- Install 'Bakery Manager' from the Odoo Apps menu
